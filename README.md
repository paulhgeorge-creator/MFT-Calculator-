# MFT-Calculator-
Python Calculator Project for Introduction to Programming with Python. 7/10/26

## Layout
```
notebooks/   Jupyter notebooks (assignments, exploration)
src/         Python source code (calculator.py)
tests/       Tests for code in src/
```

## Usage
```
uv sync
uv run python src/calculator.py   # demo
uv run pytest                     # tests
```
